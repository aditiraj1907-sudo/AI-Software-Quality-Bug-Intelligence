How it works

Five stages run in order on every scan.

  1. 1. ParseStrips strings and comments, then maps functions and blocks so rules see real code.
  2. 2. Detect27 rules for JavaScript and Python find common errors and quality issues.
  3. 3. ClassifyEach finding is filed under Security, Logic, Error handling, Performance, Resource management, Code quality or Maintainability.
  4. 4. PredictA scikit-learn model blended with each rule’s default severity estimates severity and a 0–100 risk score.
  5. 5. Explain & reportEvery finding gets a reason and a fix. Results are stored in SQLite and summarized in the dashboard and report.

Detection is pattern-based, so it can miss bugs and can flag code that is fine. The severity model learned from 100 labelled bug reports, which is a small set. Explanations come from a built-in text for each rule. A production version would use a real parser, a much larger labelled bug history, and a language model for explanations.
